# ACQ Backend 2

This is a backend application developed using Spring Boot.  
The project provides REST APIs for authentication and backend services.

---

## 🚀 Tech Stack

- Java 17
- Spring Boot
- Spring Security
- JWT Authentication
- Maven
- MySQL
-  JPA

---

## 📁 Project Structure

acqBackend2
│
├── controller
├── service
├── repository
├── entity
├── config
└── exception

---

## ⚙️ Prerequisites

Before running the project make sure you have installed:

- Java 17
- Maven
- MySQL
- Intellije

---

## 📥 Clone the Repository

Go to project folder
cd acqBackend2

Update the application.properties file.

spring.datasource.url=jdbc:mysql://localhost:3306/your_db_name
spring.datasource.username=root
spring.datasource.password=your_password

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

Run the Spring Boot main class.

Application will start on:

http://localhost:8080

Build Project
mvn clean install
